## 4. How to run each step

Environment: `.env` (gitignored) holds CLOUDFLARE_R2_*, HETZNER_DEFAULT_PROJECT_API_TOKEN, GEOCODIO_API_KEY.
Run with `set -a && . ./.env; set +a` and `.venv/bin/python`. Use `OMP_NUM_THREADS=1` for LightGBM.

```bash
python pipeline/phase0/risk_area.py 12103                      # risk polygon -> data/flood_v1/risk_12103.parquet
python pipeline/lidar/prepare.py RUN --fips 12103 \
  --ept https://s3-us-west-2.amazonaws.com/usgs-lidar-public/FL_Peninsular_Pinellas_2018 --metric-crs EPSG:6442
python pipeline/lidar/box.py create RUN    # checks the sources first; refuses if unreachable
python pipeline/lidar/box.py status RUN    # status.json from R2; also `box.py list` to catch a leftover box
python pipeline/lidar/box.py delete RUN    # ALWAYS after done / failed: a powered-off box still bills
python pipeline/train/labels.py 12103 RUN  # needs data/fl/ec_all.json (FDEM layer) and the run's buildings.parquet
python pipeline/train/train.py 12103 RUN   # needs data/flood_v1/lidar/RUN/features.parquet (download from R2)
```

Local trial without a box: `prepare.py RUN --bbox=... --local DIR` (+ `--ept ...`), then
`python pipeline/lidar/job.py data/flood_v1/lidar/RUN/urls.json WORKDIR --workers 3`, then `check_trial.py`.

## 6. Gotchas found today

- This sandbox has HTTPS only: outbound port 22 times out, so no SSH to any box. Boxes run from cloud-init and report
  through presigned R2 URLs; the box holds no credentials and has a firewall with no inbound rules.
- rockyweb.usgs.gov (LAZ tiles) refused connections all day from here and from Hetzner; `tnmaccess` and
  `prd-tnm.s3.amazonaws.com` (DEMs) worked. The LAZ originals are also in `s3://usgs-lidar` (requester pays:
  $0.09 / GB after AWS's 100 GB / month free tier; not used, not approved).
- EPT copy: EPSG:3857, z already in metres, quantised 0.01; transform with `'EPSG:3857'` -> EPSG:6442 always_xy.
  Chunk = depth-7 octree cell (~570 m); points clipped half-open so each point belongs to one chunk.
- DuckDB range joins (point in footprint over 290k x 600k rows) ran > 25 min; shapely STRtree does it in seconds.
- numpy `np.where(..., "within", "")` makes a fixed-width string array: longer labels get truncated silently.
- `ruff check --fix` removes imports it thinks unused (it removed pandas from prepare.py once).
- DOR residential use codes are 000-009 (not < 100).
- Owner names: never select `own_name` (fl_parcels), `buildingOwnerName` (FDEM), `A1_BUILDING_OWNER` (Pinellas EC).
